**Songs are out of the pipeline.** Will, 2026-10-23, when offered the Session 25 song: *"no. no songs. I think we are all burned out on Suno and its quirks."*

**Why:** the cost was never the writing — it was Suno. The style-box character cap, the artist-name filter that tightened over time and started rejecting old prompts, the inability to hold a genre change, the regenerations. The whole table got tired of fighting the tool. Songs ran through **Session 23** (`songs/session23.md`), plus the four character songs and a handful of alternates. **There is no Session 24 or 25 song, and there will not be.**

## How to apply

- ⚠ **Do not write `songs/sessionN.md` as part of a per-session pass.** Not proactively, not "for completeness," not because `CLAUDE.md`'s numbered pipeline once listed it.
- **Do not offer one at the end of a pass**, and do not mention a missing song as an outstanding item.
- **Do not check with the GM about whether she wrote one** — that check (see [[gm-is-a-repo-contributor]]) is retired along with the step.
- If Will **explicitly asks** for a song, write it; the Suno rules in `style-guide.md` still stand.
- **Do not delete or edit anything in `songs/`.** It is a record, like `images/`.

This is a workflow preference, not a canon fact. If songs come back, update this file rather than treating the revival as a contradiction. Same pattern as [[image-prompts-deprecated]].
